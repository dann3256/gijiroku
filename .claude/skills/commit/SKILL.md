# コミットの手順

## 1. 変更内容を確認する

1. `git status` と `git diff` で、何が変わったかを確認する。
2. 変更内容を日本語で2〜3行にまとめて私に伝える。

## 2. 秘密情報のチェック（必ず行う）

- `.env`、`.venv/`、APIキーらしき文字列がコミット対象に含まれていないか確認する。
- 含まれていたら、コミットせずに止めて私に知らせる。

## 3. コミットメッセージを決める

形式は `種類: 内容` 。内容は日本語で、何をしたかが一目で分かる短い文にする。

| 種類 | 使うとき |
| --- | --- |
| feat | 機能を追加した |
| fix | 不具合を直した |
| docs | README や CLAUDE.md など文書だけを変えた |
| refactor | 動きは変えずにコードを整理した |
| chore | 設定ファイルやライブラリの追加など |

例：

```
feat: メモ入力欄を追加
fix: 未記入チェックで空白だけの項目を見落とす問題を修正
docs: READMEにデモ画像を追加
```

- 1回のコミットには1種類の変更だけを入れる。複数の種類が混ざっていたら、分けることを提案する。

## 4. 私の確認を取ってからコミットする

1. 決めたメッセージを私に見せ、「これでコミットしてよいか」を聞く。
2. 了承されたら `git add` と `git commit` と'git push'を実行する。
