# Pythonのコードを書くときのルール

## 進め方（最優先）

1. コードを書く前に、何をするか・なぜそうするかを日本語で3行以内で説明する。
2. 一度に出すコードは20行以内。動作を確認してから次に進む。
3. 変更するファイルは一度に1つだけ。変更後は「どこを見ればいいか」を伝える。
4. 新しい書き方や概念は、1回につき1つだけ短く説明する。
5. 1つの作業が終わったら、理解を確かめるクイズを1問だけ出す。

## コーディング規約

- 変数名・関数名は英語（snake_case）。コメントは初心者向けの日本語で書く。
- 1つの関数は1つの役割にする。関数の先頭に「何を受け取り、何を返すか」をコメントで書く。
- エラーが出たら、直す前に原因を日本語で説明する。

## 安全のルール

- APIキーなどの秘密情報はコードに書かず、`.env` から読む。
- AIへの指示（プロンプト）には「メモにない内容を追加しない」「ない項目は空文字にする」を必ず含める。
- サンプルやテストには、実在の人名が入っていないダミーのメモを使う。

## 調べもの

- Azure の手順や設定は、Microsoft Learn MCP で最新の公式ドキュメントを確認してから答える。
- 確認できなかったことは、推測だと明示する。
